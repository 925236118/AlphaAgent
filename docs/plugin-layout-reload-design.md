# 插件布局切换与延迟重载方案

日期：2026-10-19。状态：已接入正式插件，并以独立工程测试实际生命周期、设置和界面。

## 使用方式

设置中新增「初始化时加载最近对话」开关，以及「插件布局：侧边栏 / 主屏幕」。首次使用均保持原有行为：不自动恢复对话、使用侧边栏。

选择不同布局后出现确认框。「立即刷新」会等待当前任务结束后重新加载插件；「稍后」保留当前布局，设置中显示待应用状态及「刷新插件」按钮。主屏幕模式在顶部新增 AlphaAgent 工作区，左侧为常驻对话列表，右侧保留原功能。打开脚本时会切换到脚本工作区。

最近对话取当前项目最后更新内容的有效历史。仅打开历史或更新标题不会改变排序。布局刷新会优先恢复当前会话、草稿、光标、附件、计划、待确认文件修改和当前页面，空白新对话也会保持空白。

## 设置及交互

- `load_recent_chat_on_start`：初始化时加载当前项目最近对话，默认关闭。
- `plugin_layout`：侧边栏 / 主屏幕，默认侧边栏。
- 保存目标布局后，若与当前实例布局不同，显示 ConfirmationDialog：
  - 标题：刷新 AlphaAgent。
  - 内容：布局已修改，是否立即刷新插件？刷新后将应用新布局，并恢复当前会话。
  - 确认：立即刷新。
  - 取消或关闭：稍后。保留配置，当前实例继续使用原布局，下次重新启用时生效。
- 同一布局不重复弹窗。选择“稍后”后，设置中保留“布局待应用 / 刷新插件”入口。
- 有对话生成、标题生成、压缩、搜索或工具任务时，不依靠倒计时判定任务结束；选择立即刷新后进入等待状态，在任务结束后继续，也允许取消等待。

## 定时器与生命周期

定时器方案可行，但需要同时保证执行回调的对象在禁用插件后仍然存活。

重载控制器位于 `addons/agent/scripts/plugin_reload_controller.gd`，挂到编辑器基础控件下，不挂在 AlphaAgent 插件或主面板下面。它是 `@tool` 节点，完成后会释放。周期 Timer 负责等待任务完成和检查初始化结果；SceneTreeTimer 负责延迟重新启用。

执行顺序：

1. 用户确认刷新，保存会话和输入草稿、附件引用、当前页面等临时状态。
2. 外部控制器在下一个约 0.2 秒的检查周期执行刷新，让确认弹窗及其信号回调退出。
3. 提前安排重新启用的定时回调，再禁用 `agent`。
4. 延迟约 0.2 秒，同时确认旧面板已经退出、释放；若尚未释放，继续等待。
5. 重新启用 `agent`，检查实例存在、配置和界面初始化完成。时间间隔只提供调度间隙，不能替代这些检查。
6. 恢复临时会话及草稿，展示目标布局。失败时回滚原布局并尝试重新启用，避免无限重试。
7. 释放临时控制器及定时器。

`_has_main_screen()` 必须返回实例创建时固定的布局值。Godot 添加、移除插件时都会查询它，因此保存新偏好不能改变旧实例的返回值。布局需要在 `_init()` 同步读取，早于 `_enter_tree()` 中的异步全局配置加载。

主屏幕挂载使用 `EditorInterface.get_editor_main_screen().add_child()`，设置纵向展开，由 `_make_visible()` 仅管理可见性。侧边栏继续使用 Dock 接口，并根据实例布局选择对应卸载路径。

## 主屏幕下的脚本编辑

AlphaAgent 和 Script 共用中间工作区。用户通过顶部工作区入口切换；主屏幕隐藏时不停止节点处理，也不关闭聊天或工具任务。

隔离实验发现：原 `open_resource` 工具调用 `edit_script()` 后虽然目标脚本已打开，工作区可能仍然停留在 AlphaAgent。已适配为显式切到 Script，等待一帧使界面布局完成，再打开并定位脚本。

正式工具中的调用顺序：

```gdscript
EditorInterface.set_main_screen_editor("Script")
await get_tree().process_frame
EditorInterface.edit_script(resource, line, column)
```

该顺序也避免了在隐藏脚本面板上定位时出现的 TextEdit 行号越界日志。AI 后续收到结果或完成回复时，不自动夺回工作区焦点。

## 历史与布局

主屏幕采用可拖动的左右分栏：左侧常驻历史列表，右侧复用当前功能面板。主屏幕标题取消弹出历史的入口；侧边栏继续保留。历史弹窗与常驻列表共享数据及列表组件，选中项保持同步。

原历史的 `time` 是无时区的本地创建时间。现在增加内容更新时间 `updated_at`，旧记录回退创建时间并转换到统一时区；纯打开记录或标题生成不更新最近内容时间。压缩为上下文摘要的历史也支持恢复。

恢复优先级：布局刷新前的临时状态 > 初始化自动加载最近对话 > 空白新对话。布局刷新前是空白新对话时，同样保留空白状态。自动恢复只显示已保存内容，不自动发送请求或重新执行历史工具。

## 隔离实验与证据

最终在全新工程中的结果：

| Godot | 功能检查 | 导入及运行日志错误/警告 | 进程退出码 |
|---|---|---|---|
| 4.5.2 stable | 46 / 46 通过 | 0 | 0 |
| 4.7.2 stable | 46 / 46 通过 | 0 | 0 |

逐项结果：[4.5.2](../tests/plugin_settings/results-4.5.2.json)、[4.7.2](../tests/plugin_settings/results-4.7.2.json)。最初的 31 项原型实验结果保留在 `tests/layout_probe` 中供追溯。

测试入口：`tests/plugin_settings/run.ps1`。脚本复制当前 `addons` 到全新的临时工程，只重定向副本的配置目录，执行真实的设置及重载逻辑。使用独立应用名、配置路径和历史目录，不读写用户的真实插件配置。原 `tests/layout_probe/run.ps1` 已改为调用正式集成测试。

执行默认测试：

```powershell
./tests/plugin_settings/run.ps1
```

指定其它 Godot 版本：

```powershell
./tests/plugin_settings/run.ps1 -Godot 'D:\软件安装程序\Godot\Godot_v4.5.2-stable_win64_console.exe'
```

输出目录包含 `import.log`、`run.log` 和 `results.json`。当前验证覆盖：

- 刷新确认框显示、稍后保留旧实例及待应用设置。
- 外部 Timer 禁用并重新启用插件。
- 当前实例布局固定，新实例按新布局注册。
- 当前 AlphaAgent 面板挂入主屏幕并可显示。
- 实际 `open_resource` 工具打开、定位脚本并显式切换工作区。
- 在内置 CodeEdit 中产生未保存编辑，工作区切换保留内容及光标。
- 插件处于主屏幕模式时，通过内置脚本保存菜单把编辑结果写入文件。
- 插件重新加载保留未保存脚本，重载后继续编辑并保存。
- 最近历史恢复开关、旧数据时区、无历史、损坏历史保留和压缩摘要恢复。
- 当前会话优先于最近历史、空白新对话、草稿光标、文件和图片附件、计划及待确认文件修改恢复。
- 实际异步工具执行期间延后刷新、取消等待和任务完成后自动继续。
- 模拟初始化超时后回退布局，恢复草稿及原布局偏好。
- 多次往返后只有一个 AlphaAgent 面板。

这是无界面自动化验证，确认了实际编辑器对象、缓冲区、左右分栏结构和文件保存行为。弹窗通过真实按钮的信号驱动，异步工具采用延迟测试工具，回退采用超时故障注入。未覆盖人工点击、屏幕显示效果、鼠标拖动、快捷键冲突和真实网络生成；这些仍需交互验收。
