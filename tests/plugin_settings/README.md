# 设置集成检查

`run.ps1` 复制插件到临时项目，并将复制品的配置目录改为独立位置，不会读写开发者当前的 AlphaAgent 配置。

使用 `-ResetOnly` 检查初始化配置按钮、确认与取消、任务忙碌阻止、版本范围、嵌套技能删除、记忆清空、默认配置恢复和自动刷新，同时验证历史、项目文件及待确认快照保留。

同一组检查还会在编辑器运行期间修改配置版本，再禁用并重新启用插件，验证预加载资源与各类配置路径均使用新版本。

重置入口另有旧设置对象兼容检查：新增版本字段为 null、空版本参数、未就绪路径、混合版本路径，以及确认前版本变化，都不会误删配置或产生参数类型错误。

其他检查入口：默认运行布局和设置检查，`-UiOnly` 检查技能滚动布局，`-FilesOnly` 检查文件修改列表。可用 `-Godot` 指定 Godot 控制台程序路径。

`-ContextOnly` 检查旧模型容量迁移、用量百分比边界、未知窗口、压缩阈值、压缩后及会话切换时的统计更新，并验证快速模型和火山引擎压缩客户端配置。所有请求配置均在隔离项目中验证，不调用真实模型 API。
